ANALYZE


Только команда называется ANALYZE.

ANALYZE users;

Что происходит:

PostgreSQL не выполняет твой SELECT и не строит план конкретного запроса. Он обновляет статистику по таблице users, чтобы потом планировщик лучше оценивал запросы.

Упрощённо:

ANALYZE users
      ↓
PostgreSQL изучает данные таблицы
      ↓
собирает статистику
      ↓
обновляет оценки
      ↓
планировщик потом использует эту статистику

Например, PostgreSQL должен понять:

«Сколько примерно строк с user_id = 99999 находится в orders?»

После:

ANALYZE orders;

у него будет более актуальная статистика, и он сможет лучше выбрать между:

Seq Scan
Index Scan
Bitmap Scan
Nested Loop
Hash Join
...
Поэтому не путай три команды:
ANALYZE users;

→ обновить статистику таблицы

EXPLAIN
SELECT ...;

→ посмотреть предполагаемый план, запрос не выполняется

EXPLAIN ANALYZE
SELECT ...;

→ посмотреть план + реально выполнить запрос + получить фактические показатели
