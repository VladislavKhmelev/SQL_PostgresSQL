COALESCE

| name  | salary | bonus |
| ----- | -----: | ----: |
| Иван  | 120000 | 10000 |
| Анна  | 140000 |  NULL |
| Пётр  |  90000 |  5000 |
| Мария | 130000 |  NULL |

Нужно вывести:

name
salary
bonus
total_salary

Где:

total_salary = salary + bonus

Но если bonus равен NULL, total_salary тоже станет NULL.

Используй COALESCE, чтобы этого не произошло.

Попробуй сам.


select 
name,
salary,
bonus,
salary + COALESCE(bonus,0) as total_salary
from employees;
~~~
