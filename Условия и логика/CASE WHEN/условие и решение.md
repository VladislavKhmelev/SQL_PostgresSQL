Условие: отделы, где:

больше одного сотрудника;
средняя зарплата выше 90 000;
есть completed-заказы;
нет cancelled-заказов.

Твоё решение:

SELECT
    department_name
FROM departments
INNER JOIN employees
    ON employees.department_id = departments.id
LEFT JOIN orders
    ON orders.employee_id = employees.id
GROUP BY department_name
HAVING COUNT(DISTINCT employees.id) > 1
   AND AVG(salary) > 90000
   AND COUNT(CASE WHEN orders.status = 'completed' THEN 1 END) >= 1
   AND COUNT(CASE WHEN orders.status = 'cancelled' THEN 1 END) = 0;

Задача

Нужно вывести сотрудников и создать столбец salary_status.

Правила:

Если зарплата ≥ 150000 → TOP
Если зарплата ≥ средней зарплаты своего отдела → ABOVE_AVG
Если зарплата ≥ 100000 → GOOD
Иначе → LOW

Вывести:

name
department
salary
salary_status





SELECT
r.name,
r.salary,
department,
CASE
when salary >= 150000 then 'TOP'
when r.salary >= (
    select
    avg(r1.salary)
    from employees r1
    where r1.department_id = r.department_id
) then 'ABOVE_AVG'
when salary >= 100000 then 'GOOD'
else 'LOW'
end as salary_status

from employees r
join departments
on r.department_id = departments.id;
