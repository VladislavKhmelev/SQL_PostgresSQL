Создай:

etl_stage.customers
etl_stage.orders

etl_target.customers
etl_target.orders
etl_target.customer_stats

Создай необходимые схемы.

etl_stage

Таблицы предназначены для сырого входящего потока.

etl_target

Таблицы предназначены для чистых данных.

Необходимо самостоятельно определить и создать:

PRIMARY KEY;
FOREIGN KEY;
NOT NULL;
UNIQUE;
DEFAULT;
CHECK;
индексы;
связи между таблицами.

customer_stats должна быть рассчитана как отдельная целевая сущность, связанная с клиентом.

Задача — спроектировать DDL так, чтобы структура была пригодна для последующего ETL/ELT-процесса с INSERT, UPDATE, UPSERT и MERGE.



CREATE SCHEMA etl_stage;

CREATE TABLE etl_stage.customers (
id text,
name text,
email text,
city text

);


CREATE TABLE etl_stage.orders (
id text,
customer_id text,
amount text,
status text,
created_at text

);

CREATE SCHEMA etl_target;

CREATE TABLE etl_target.customers (

id int PRIMARY KEY,
name text NOT NULL,
email text NOT NULL,
CONSTRAINT el UNIQUE(email),
city text NOT NULL,
created_at TIMESTAMP NOT NULL
);

CREATE TABLE etl_target.orders (
id int PRIMARY KEY,
customer_id int NOT NULL,
CONSTRAINT cd FOREIGN KEY (customer_id) REFERENCES etl_target.customers(id)
on UPDATE CASCADE,
amount numeric(10,2) CHECK(amount >=0) NOT NULL,
status text NOT NULL DEFAULT 'new',
created_at TIMESTAMP NOT NULL

);

CREATE TABLE etl_target.customer_stats (
id int PRIMARY KEY,
customer_id int NOT NULL,
CONSTRAINT cd FOREIGN KEY (customer_id) REFERENCES etl_target.customers(id)
on UPDATE CASCADE,
orders_count int CHECK(orders_count>= 0) NOT NULL,
total_amount numeric(10,2) CHECK(total_amount>=0) NOT NULL,
updated_at TIMESTAMP NOT NULL

);


CREATE INDEX idx
on etl_target.orders(customer_id);

CREATE INDEX idx1
on etl_target.customer_stats (customer_id);
