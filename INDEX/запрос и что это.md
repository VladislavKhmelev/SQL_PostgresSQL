Если хочешь обновить статистику

После существенных изменений данных можно отдельно выполнить:

ANALYZE users;

А затем снова:

EXPLAIN ANALYZE
SELECT *
FROM users
WHERE email = 'user99999@mail.ru';
Важное различие
ANALYZE users;

→ обновляет статистику таблицы.

EXPLAIN ANALYZE SELECT ...;

→ показывает план и реально выполняет запрос.
