NTILE


Используем нашу sales.

Нужно каждому клиенту присвоить группу по размеру суммы продажи:

1 → самые маленькие
2 → следующие
3 → следующие
4 → самые большие

Но группы должны считаться отдельно для каждого клиента.


| id | customer_id | date       | amount |
| -: | ----------: | ---------- | -----: |
|  1 |           1 | 2026-08-01 |    100 |
|  2 |           1 | 2026-08-02 |    150 |
|  3 |           1 | 2026-08-03 |    120 |
|  4 |           2 | 2026-08-01 |    500 |
|  5 |           2 | 2026-08-02 |    450 |
|  6 |           2 | 2026-08-03 |    600 |



with tt as (
    SELECT
    *,
    NTILE(4) over(PARTITION BY customer_id
    ORDER BY amount) as r
    from sales
    
)

select
*
from tt;
