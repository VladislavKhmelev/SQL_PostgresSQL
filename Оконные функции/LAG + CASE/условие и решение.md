LAG + CASE


Для каждой транзакции определить:

UP — если текущая сумма больше предыдущей
DOWN — если текущая сумма меньше предыдущей
SAME — если равна предыдущей
для первой транзакции клиента — FIRST


with tt as (
    SELECT
    *,
    lag(amount) OVER(PARTITION BY customer_id ORDER BY date, id) as r
    from sales
)
SELECT
*,
case 
WHEN amount > r then 'UP'
when amount< r then 'DOWN'
when amount = r then 'SAME'
end as r1
from tt;


Для каждой транзакции посчитать:

насколько amount изменился относительно предыдущей транзакции клиента в процентах.

Формула:

(current - previous) / previous × 100

with tt as (
    SELECT
    *,
    lag(amount) OVER(PARTITION BY customer_id ORDER BY date, id) as r
    from sales
)
SELECT
*,
(amount - r) / nullif(r,0) * 100 as r1
from tt;


Для каждого клиента получить сумму две транзакции назад.

with tt as (
    SELECT
    *,
    lag(amount, 2) over(PARTITION BY customer_id ORDER BY date, id) as r
    from sales
)
SELECT
*
from tt;
