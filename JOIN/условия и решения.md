Условие задачи:
Для каждого отдела вывести:

количество уникальных сотрудников;
количество completed-заказов;
общую сумму completed-заказов;
сохранить все отделы, даже без заказов.

Твоё решение:

select

department_name,

count(DISTINCT employees.id) as r,

count(case when orders.id is not null then 1 end) as r1,

COALESCE(sum(case when orders.id is not null then amount end),0) as r2

from departments

LEFT JOIN employees

on employees.department_id = departments.id

LEFT JOIN orders

on orders.employee_id = employees.id

AND status = 'completed'

GROUP BY department_name;

SELECT
    department_name,
    count(DISTINCT employees.id) as r,
    COALESCE(avg(salary),0) as r1,

Условие: Вывести отделы, в которых либо нет сотрудников, либо средняя зарплата сотрудников меньше 100000.

Решение:

SELECT
    d.department_name,
    COUNT(e.id) AS employee_count,
    AVG(e.salary) AS avg_salary
FROM departments d
LEFT JOIN employees e
    ON d.id = e.department_id
GROUP BY d.department_name
HAVING COUNT(e.id) = 0
    OR AVG(e.salary) < 100000;

Условие: Для каждого отдела посчитать количество сотрудников, среднюю зарплату и максимальную зарплату. Отсортировать по средней зарплате от большей к меньшей.

Решение:

SELECT
    d.department_name,
    COUNT(e.id) AS employee_count,
    AVG(e.salary) AS avg_salary,
    MAX(e.salary) AS max_salary
FROM departments d
LEFT JOIN employees e
    ON d.id = e.department_id
GROUP BY d.department_name
ORDER BY avg_salary DESC;




Условие: Посчитать среднюю зарплату в каждом отделе, включая отделы без сотрудников. Для отделов без сотрудников показать 0.

Решение:

SELECT
    department_name,

    ON employees.department_id = departments.id
