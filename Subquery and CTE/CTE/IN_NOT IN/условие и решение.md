IN и NOT IN


Задача №1 — IN

Найди сотрудников, которые работают в отделах с названием IT или Marketing.

Вывести:

name | department | salary


with tt as (
    select
    *
    from departments
    INNER JOIN employees
    on departments.id = employees.department_id
),

tt1 as (
    select
    name
    from tt
    where tt.department_id in (
        select
        id
        from departments
        where department in ('IT', 'Marketing')
    )
)

select
name
from tt1;


Задача

Найди сотрудников, которые работают НЕ в отделах IT и Marketing.


with tt as (
    select
    *
    from departments
    INNER JOIN employees
    on departments.id = employees.department_id
),

tt1 as (
    select
    name,
    department_id,
    salary
    from tt
    where tt.department_id not in (
        select
        id
        from departments
        where department in ('IT', 'Marketing')
    )
)
