EXISTS / NOT EXISTS

Задача №1 — EXISTS

Найди отделы, в которых есть хотя бы один сотрудник с зарплатой больше 140 000.

| id | department |
| -: | ---------- |
|  1 | IT         |
|  2 | Sales      |
|  3 | HR         |
|  4 | Marketing  |

| id | name    | department_id | salary |
| -: | ------- | ------------: | -----: |
|  1 | Иван    |             1 | 120000 |
|  2 | Анна    |             1 | 140000 |
|  3 | Пётр    |             2 |  90000 |
|  4 | Мария   |             2 | 130000 |
|  5 | Сергей  |             2 | 110000 |
|  6 | Олег    |             3 |  70000 |
|  7 | Елена   |             4 | 150000 |
|  8 | Дмитрий |             4 | 130000 |



with tt as (
select 
*
from departments
INNER JOIN employees
on departments.id = employees.department_id
),

tt1 as (
    select
    department
    from tt
    where EXISTS (
        SELECT
        1
        from employees 
        where salary > 140000 and tt.department_id = employees.department_id
        )
)

SELECT DISTINCT
tt1.department
from tt1;


Новая задача
>> 
>> Найди отделы, в которых нет ни одного сотрудника с зарплатой меньше 100 000.


with tt as (
    select
    *
    from departments
    INNER JOIN employees
    on departments.id = employees.department_id
),

tt1 as (
    select
    department
    from tt
    where not EXISTS (
        SELECT
        1
        from employees e
        where e.salary < 100000 and e.department_id = tt.department_id
    )
)

select distinct
department
from tt1;
