Задача №2 — Subquery

Теперь немного сложнее.

Нужно найти сотрудников, которые получают зарплату выше средней зарплаты именно в их городе.

select 
*
from employees t 
where salary > (
    select
    avg(salary)
    from employees
    where city = t.city
);







Задача №3

Найди сотрудников, которые получают максимальную зарплату в своём городе.


select 
*
from employees t 
where salary = (
    select 
    max(salary)
    from employees
    where city = t.city
);
