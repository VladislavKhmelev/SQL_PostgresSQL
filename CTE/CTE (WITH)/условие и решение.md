Теперь сделаем чуть интереснее.

Нам нужно получить среднюю зарплату по каждому городу.


with tt as (
    select 
    city
    avg(salary)
    from employees
    GROUP BY city
)

select 
*
from tt;




Задание

Нужно вывести только те города, где средняя зарплата больше 100 000.


with tt as (   
    select  
    city,
    avg(salary) as t1
    from employees
    group by city
)

select 
*
from tt
where t1 > 100000;




Теперь попробуем ситуацию, где одного промежуточного результата недостаточно.

У нас всё те же сотрудники.

Нужно найти сотрудников, которые одновременно:

получают зарплату выше средней по своему городу;
и при этом их зарплата не меньше 80 000.


with tt as (
    select
    city,
    avg(salary) as e
    from employees
    GROUP BY city
)

select 
*
from employees t
join tt
on t.city = tt.city
where t.salary > tt.e 
and t.salary >= 80000;





Задача

Найди города, в которых:

средняя зарплата выше 80 000;
и количество сотрудников в городе не меньше 2.


with tt as (
    select 
    city,
    avg(salary) as e,
    count(*) as e1
    from employees
    GROUP BY city
)

SELECT
*
from tt
where tt.e > 80000 and tt.e1 >=2;
