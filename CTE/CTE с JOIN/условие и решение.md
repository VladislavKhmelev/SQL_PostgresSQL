Здесь мы впервые столкнём CTE с JOIN.
Используем CTE + обычную таблицу одновременно.

Нужно вывести имя сотрудника, его зарплату и среднюю зарплату его города:


with tt as (
    SELECT
    city,
    avg(salary) as avg_s
    from employees
    GROUP BY city

)


select 

t.name,
t.salary,
t1.avg_s
from employees t
join tt t1
on t.city = t1.city
where t.salary > t1.avg_s;



Есть та же таблица employees:

Задание:

Найди сотрудников, которые получают максимальную зарплату в своём городе.


with tt as (
    SELECT
    city,
    max(salary) as e
    from employees
    GROUP BY city
)

select 
*
from employees t
join tt
on t.city = tt.city
where t.salary  = tt.e;
